#  Weather Web Application

A simple and responsive weather web application built using **HTML, CSS, and JavaScript**. It fetches real-time weather data using a weather API based on user input (city name) and dynamically updates the UI according to weather conditions.

---

##  Live Demo
https://silver-elf-47cb18.netlify.app

---

## Features
- Search weather by city name
- Real-time temperature display
- Weather condition updates (sunny, cloudy, rainy, etc.)
- Dynamic UI changes based on weather
- Responsive design for mobile and desktop

---

## Tech Stack
- HTML
- CSS
- JavaScript
- Weather API (OpenWeatherMap / similar)

## How It Works
1. User enters a city name
2. JavaScript sends request to Weather API
3. API returns weather data
4. UI updates dynamically based on response

---

##  API Note
This project uses a weather API key stored in JavaScript for simplicity.  
In production applications, API keys should be secured using backend services or environment variables.
